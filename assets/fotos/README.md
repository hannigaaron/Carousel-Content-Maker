# Fotos

Hier liegen die Bilder, aus denen die Slides gebaut werden. Der Renderer holt
sie direkt von hier — keine API, keine Verbindung nach außen.

## Hochladen

Über die GitHub-Weboberfläche: in diesen Ordner gehen → *Add file* →
*Upload files* → Bilder hineinziehen → *Commit changes*. Mehrere auf einmal
geht, ganze Ordner auch.

## Was hier reingehört

- **JPG oder PNG.** HEIC vom iPhone wird vom Renderer nicht gelesen — in der
  Fotos-App beim Export "Automatisch" statt "Original" wählen, dann kommt JPG.
- **Originalgröße**, nicht die kleinen Vorschauversionen. Für 1080×1350 sollte
  das Bild mindestens 1080 px breit sein.
- **Hochformat bevorzugt** (4:5 oder 3:4). Querformat geht, wird aber
  beschnitten.
- **30–40 Bilder reichen für Monate.** Lieber kuratiert als vollständig — jedes
  Bild landet dauerhaft in der Repo-Historie.

## Was ein gutes Slide-Foto ausmacht

Der Text sitzt im **unteren Drittel**. Dort sollte das Bild ruhig sein: keine
Fenster, keine Spiegelungen, keine Schrift, kein Gesicht. Ein Bild mit
Bewegung oben und ruhiger Fläche unten ist ideal.

Und: Das Motiv soll die Situation zeigen, über die der Slide spricht. Ein
gutes Bild von dir am falschen Ort ist ein schlechtes Slide-Foto.
