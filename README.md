# Carousel Content Maker

Bildmaterial-Repository für die Erstellung von Social-Media-Carousel-Inhalten.

## Inhalt

Das Repository enthält Foto-Assets (`.jpeg`, `.HEIC`), die als Quellmaterial für
Carousel-Posts dienen.

## Branches

| Branch | Zweck |
| --- | --- |
| `main` | Hauptbranch mit dem aktuellen Asset-Bestand |
| `assets/fotos` | Ablage für hochgeladene Foto-Uploads |

## Arbeiten mit dem Repository

```bash
git clone https://github.com/hannigaaron/Carousel-Content-Maker.git
cd Carousel-Content-Maker
```

Neue Assets werden per Commit auf einem Feature-Branch hinzugefügt und über einen
Pull Request nach `main` gebracht.
